# 🍱 今天吃什麼？命運轉盤

選擇困難救星：自訂想吃的選項，轉一下轉盤，讓命運幫你決定！

🔗 **線上試玩：** https://yjy-ying.github.io/what-to--eat/

---

## 規格書

### 1. 專案名稱
今天吃什麼？命運轉盤（What to Eat Wheel）

### 2. 發想動機
每天中午和朋友最常卡住的問題就是「要吃什麼」，常常討論十分鐘還決定不了。
我想做一個可以自訂選項、依口味篩選，並用「轉盤」這種有趣方式幫忙做決定的網頁。

### 3. 目標使用者
選擇困難的大學生、上班族；需要和朋友一起快速決定吃什麼的人。

### 4. 功能規格

**(1) 命運轉盤**
- 用 Canvas 畫出彩色轉盤，每格顯示「食物名稱＋類別 emoji」，格子大小依喜好度決定
- 按中間「轉！」按鈕（或鍵盤空白鍵）開始旋轉
- 旋轉約 4～5 秒，使用減速動畫（ease-out），最後停在結果上
- 指針經過每一格會發出「滴」聲並晃動
- 結果由程式先隨機抽出，再計算轉盤要停的角度，保證指針指到的格子＝結果
- 轉盤上的文字不論在哪個位置都是正的，不會上下顛倒

**(2) 結果視窗**
- 跳出彈窗顯示結果、類別與喜好度，並撒彩帶＋播放音效
- 「再轉一次」與「就決定是你了」兩個按鈕

**(3) 篩選條件**
- 類別：飯類／麵類／輕食／速食／飲料／小吃，可多選
- 取消勾選的類別不會出現在轉盤上，轉盤即時重畫

**(4) 轉盤規則**
- 「不要跟上一次一樣」：開啟後不會連續抽到同一個
- 「依喜好度調整機率」：每個選項有 1～5 顆星，星越多格子越大、越容易抽中；關掉後每格一樣大、機率相同

**(5) 選項管理**
- 新增選項：輸入名稱、選擇類別
- 防呆：名稱不可重複、最多 16 個選項；新增的選項若不符合篩選，會跳提示
- 點星星可循環調整喜好度（1→5），按 ✕ 刪除；不符合篩選條件的選項會變淡顯示
- 三組預設清單一鍵套用：午餐／宵夜／飲料；可一鍵還原預設

**(6) 紀錄與統計**
- 顯示最近 10 次結果與時間
- 長條圖統計最常抽到的前 5 名
- 可清除紀錄

**(7) 其他**
- 深色／淺色模式切換
- 音效開關
- 所有設定、選項、紀錄存在 localStorage，重新整理不會消失
- RWD：電腦左右兩欄，手機自動變成上下排列

### 5. 畫面配置
- 上方：標題、音效按鈕、深色模式按鈕
- 左側（手機在上方）：轉盤、結果文字
- 右側（手機在下方）：三個分頁「篩選／選項管理／紀錄」

### 6. 使用流程
打開網頁 → （可選）選類別、套用清單 → 按「轉！」→ 轉盤減速停下 → 跳出結果視窗 → 決定 or 再轉一次 → 結果自動記錄到「紀錄」

### 7. 技術規格
- 單一 `index.html`，HTML + CSS + JavaScript 全部寫在同一個檔案
- 不使用任何外部套件；轉盤與彩帶用 Canvas 繪製，音效用 Web Audio API 產生
- 部署：GitHub Pages
